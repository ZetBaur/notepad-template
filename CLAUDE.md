# CLAUDE.md — Notepad (шаблон)

Приложение слушает звук собеседования, распознаёт речь локально и показывает подсказку только тебе.
Технические вопросы и live-кодинг — обычный ответ. Поведенческие («почему хотите у нас работать», «расскажите о провале») —
подсказка строится **только из твоей личной базы знаний**: бот напоминает твои же факты. Языки — английский и русский.

## С чего начать

- Профилей нет (`profiles/` пуст или нет `profiles/<имя>/bot/knowledge.md`) → скажи пользователю: **`/start`**, затем **`/clear`**, затем **`/setup-profile`**.
- Состояние настройки — в `.claude/setup-state.md` (читай его первым, он переживает `/clear`).

## Правила (все сессии)

- **Общение:** язык и стиль — из `.claude/setup-state.md` (спрашивается в `/start`). По умолчанию: коротко, простыми словами, один вопрос за раз. Перед большой работой — сначала сказать, что будешь делать.
- **Только факты пользователя.** Слова пользователя о своём опыте = факт, не перепроверять. Бот и агент ничего не выдумывают: нет данных — вопрос пользователю или строка в `profiles/bot/GAPS.md`. Забытые детали — нормально: предложи формулировку и спроси, где/в какой компании/проекте это было.
- **Необратимое, публичное, платное** (push, публикация, отправка писем/откликов, оплата) — только с подтверждения. Ключи и личные данные не показывать и не коммитить.
- **Баги — только измерением:** временные логи в обоих концах (Rust `eprintln!`, JS → Rust-команда для логов, помечать `DEBUGLOG`), найти шаг без ожидаемой строки, починить, убрать логи. Не гадать по коду.
- **Советы блогеров и внешних источников — гипотезы.** Нет проверяемых фактов — пометить «гипотеза» и дать способ проверки.
- **Главный критерий** любого решения: повышает ли оно шанс оффера (и для бота — скорость и качество ответа, проверяется замером). Не полировать то, что оффер не увеличивает. Каждый готовый ответ в базе проверять: (1) что лишнее, (2) чего не хватает, (3) выдержит ли вопрос «а подробнее?». Не открывать лишних слабых мест.
- **Браузер (Claude in Chrome / computer use) — только с явного разрешения** на конкретное действие.
- **Актуальность базы — работа агента:** узнал новый или исправленный факт — сразу обнови `profiles/<профиль>/bot/knowledge.md` и сообщи одной строкой. Исключение: факт противоречит `profiles/bot/FORBIDDEN.md` — спросить.
- **После любой правки промпта или базы знаний — навык `eval`** (тест с реальным промптом). Затем «Reload knowledge» в настройках приложения.
- **Ведение задач:** замеченное важное — сразу в `TODO.md`; сделанное и проверенное — в `TODO-DONE.md` (дата, итог, как проверено). В конце ответа: «Можно /clear» или «Пока не чисти: …».

## Что делать по ситуации (навыки подбираются по смыслу; перед записью файлов — подтверждение)

| Ситуация у пользователя | Навык |
|---|---|
| Написал рекрутёр, прислали JD, назначили интервью, оффер, отказ | `recruiter-update` |
| Закончился звонок / интервью, нужен разбор | `after-call` |
| Поправили базу или промпт; «проверь бота» | `eval` |
| Нужен живой голосовой тест приложения | `say-test` |
| Пересобрать и установить приложение | `rebuild` |
| Совет, видео, скрин, чужое резюме для LinkedIn/резюме; замер LinkedIn Analytics | `profile-update` |
| Спорное решение влияет на оффер, фактов мало | `cross-check-llms` |

## База знаний (подробности — `docs/bot/KNOWLEDGE.md`)

- Данные лежат в `profiles/` (в git не попадает; это симлинк в `~/Library/Application Support/dev.notepad.assistant/profiles`).
- **Профиль = папка `profiles/<профиль>/`**; `bot/knowledge.md` — единственный файл, который идёт в промпт бота. Остальное (`linkedin/`, `resume/`, `analytics.md`) в бот не попадает.
- Общее для всех профилей: `profiles/bot/FORBIDDEN.md` (запреты), `profiles/bot/GAPS.md` (вопросы без ответа), `profiles/companies/`, `vacancies/`, `interviews/`.
- Ответы в базе: разговорные, 3–5 коротких фраз по 8–15 слов, каждая с новой строки.
- Приложение само дописывает к вопросам `[Routing hint: …]` и `[Rule: …]` (`llm.rs`, `prepare_question`).

## Структура

```
app/               — Tauri-приложение (src/ фронтенд, src-tauri/ Rust, agent-sidecar/ мост к Claude Agent SDK, eval/ тест промпта)
docs/              — bot/ (KNOWLEDGE, критерии ответа, список вопросов), linkedin/, resume/, COMMANDS.md
profiles/          — личные данные (не в git)
.claude/commands/  — /start, /setup-profile
.claude/skills/    — навыки по ситуации
```

Запуск: `pnpm install` в `app/`, затем `pnpm dev`. Готовое приложение: `/Applications/Notepad.app` (навык `rebuild`). Авторизация — через залогиненный Claude Code, ключ не нужен. Папку проекта после сборки не переносить (путь к `agent-sidecar` зашит).
