# Notepad

Личный помощник на собеседовании. Слушает звук звонка, распознаёт речь у вас на компьютере и показывает подсказку только вам. На вопросы про вас бот отвечает из вашей базы знаний и ничего не выдумывает.

## Как начать

1. Откройте эту папку в VS Code с Claude Code (нужен вход в Claude Code, ключ не нужен).
2. Напишите `/start`. Бот проверит компьютер, предложит поставить нужное и подготовит папку для ваших данных.
3. Выполните `/clear`, потом `/setup-profile`: бот попросит ваше резюме и настроит базу знаний под вас.

Дальше всё по шагам, один вопрос за раз.

## Что нужно

- Mac (macOS).
- Claude Code с входом в аккаунт.
- Xcode Command Line Tools, Rust, Node.js и pnpm. `/start` проверит их и предложит поставить, ничего не ставится без вашего «да».

## Что внутри

- Подсказки на технические вопросы и на live-кодинг (текст и скриншот).
- На вопросы про вас («расскажите о себе», «почему уходите») бот напоминает ваши же факты из базы знаний.
- Распознавание речи идёт локально, звук никуда не отправляется.
- Список команд: `docs/COMMANDS.md`.
