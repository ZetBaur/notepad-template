# Аналитика профиля «{{ПРОФИЛЬ}}» (раз в неделю, в один и тот же день и время)

Источник: раздел «Аналитика» LinkedIn + почта. Цифры даёт владелец (скрин). Один замер = одна строка.
Правила: профиль держим минимум 2 недели без правок; за раз меняем один элемент (запись — `linkedin/changes.md` и `linkedin/EXPERIMENTS.md`). Выборки маленькие (десятки просмотров) — не делать вывод по одной неделе.
