Живой тест голосом. Коротко, **один вопрос за раз**. Ничего не чини сам: только отчёт.

Вопросы: `app/agent-sidecar/eval/questions-<профиль>.json`, нет файла — общий `questions.json` (скажи об этом). Формат `{kind, q}`, kind = tech | border | behav | company.

1. **Подготовка.** Скажи пользователю: запустить приложение (при необходимости навык `rebuild`), выбрать профиль, включить захват звука с колонок (чтобы приложение слышало `say`), очистить панель ответов. Не говори «готово» за него.
2. **Язык.** Спроси: английский, русский или оба. Голоса: английский `Samantha`, русский `Milena` (проверь `say -v '?'`). Русский текст озвучивать только русским голосом.
3. **Сколько вопросов** и **какой процент технических** — по отдельному вопросу, дожидаясь ответа. `tech = round(N*%/100)`, остальные из `border`, `behav`, `company` поровну.
4. **Выбор.** Случайно, без повторов с прошлого прогона (`eval/out/say-test-last.json`). Покажи итог одной строкой («10 вопросов: 4 tech, 6 прочих»), тексты не показывай. Порядок запиши в `say-test-last.json`.
5. **Ждать «готово».** Пока пользователь не напишет — ничего не озвучивай.
6. **Озвучка.** По каждому: `say -v <голос> "<вопрос>"`, затем `sleep 10`. Номера вслух не говорить. Между вопросами печатай «№k озвучен». Серией в одном Bash (`timeout` 600000, при >30 вопросов — по частям).
7. **Сбор.** Попроси: «Скопируй все ответы из панели и вставь сюда».
8. **Разбор.** Сопоставь ответы с вопросами по тексту. Проверь каждый по `profiles/bot/FORBIDDEN.md`, `GAPS.md`, `docs/bot/BOT-ANSWER-CRITERIA.md` и фактам базы профиля (не врёт ли про опыт, компании, цифры). Для каждого: ок / проблема + причина одной строкой, настоящая или ложное срабатывание. Задержка: есть время в панели — посчитай до первого слова; нет — скажи прямо, что замера нет.
9. **Отчёт.** Сколько ок из скольких, проблемы, что предлагаешь исправить. Сохрани в `app/agent-sidecar/eval/out/say-test-<дата>.md`; настоящие проблемы — в `TODO.md`.
10. Последняя строка: «Отчёт: out/say-test-<дата>.md. Можно /clear.»
