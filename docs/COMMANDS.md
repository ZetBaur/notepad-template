# Команды и навыки

## Команды (вызываешь сам)

| Команда | Что делает |
|---|---|
| `/start` | Один раз: очищает чужое, проверяет и настраивает окружение, создаёт папку данных. В конце скажет: «`/clear`, потом `/setup-profile`». |
| `/setup-profile` | Просит резюме или копию LinkedIn, заполняет базу знаний, задаёт вопросник, обновляет резюме и ссылки, запускает проверку бота. Можно вызывать повторно, чтобы дополнить базу. |
| `/mock` | Мок-собеседование: вопросы озвучиваются по одному (поведенческие блоками по 10, потом 10 технических), ты отвечаешь вслух по тезисам бота. «Дальше / повтори / слабо / стоп». | Перед интервью, для тренировки |

## Навыки (агент включает сам по смыслу; можно и попросить словами)

| Навык | Когда |
|---|---|
| `recruiter-update` | Написал рекрутёр, прислали вакансию, назначили интервью, оффер, отказ |
| `after-call` | Закончился звонок: разбор, правки базы |
| `eval` | После правки базы или промпта: тест бота |
| `say-test` | Живой голосовой тест приложения |
| `rebuild` | Пересобрать и установить приложение |
| `profile-update` | Совет, видео, скрин для LinkedIn или резюме; замер LinkedIn Analytics |
| `cross-check-llms` | Спорное решение, где мало фактов |
