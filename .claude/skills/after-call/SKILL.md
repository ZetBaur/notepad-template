Разбери прошедшее собеседование вместе с пользователем, коротко, простыми словами. Критерий один: повышает ли правка шанс оффера. Только факты пользователя, ничего не выдумывать.

1. Найди последний файл: `ls -t profiles/interviews/*.md | head -3` (приложение пишет их само). Прочитай его; пользователь мог заполнить «Итог» и в вопросах поле «Что сказал реально / оценка». Прочитай `profiles/bot/GAPS.md`; по базе профиля (`profiles/<профиль>/bot/knowledge.md`) ищи `grep`, целиком не читай.
2. Таблица по каждому вопросу: вопрос · что подсказал бот · оценка (ок / слабо / пробел / выдумка). Пустые оценки не додумывай: спроси одним сообщением, как было.
3. Для каждого «слабо / пробел / выдумка» проверь: (1) что в ответе лишнее для оффера, (2) чего не хватает, (3) выдержит ли «а подробнее?». Предложи конкретную правку записи в `knowledge.md` или карточки компании. Нужны новые факты — задай вопросы.
4. Правки — только после «ок». Затем: новый запрет — в `profiles/bot/FORBIDDEN.md`; новый опасный вопрос — в `app/agent-sidecar/eval/questions.json`; затем навык `eval`.
5. Закрытые пробелы вычеркни из `GAPS.md`; нерешённое — в `TODO.md`; сделанное и проверенное — в `TODO-DONE.md`. В конец файла звонка — строка «Итог разбора».
6. Последняя строка: «Сохранено в TODO/файле звонка. Можно /clear.»
